# Week 3: Crank-Nicolson Foundation

This lesson uses the shared `pde_solver` package to solve the 1D heat equation
with the Crank-Nicolson method. It is unconditionally stable and second-order
accurate in time for smooth solutions.

1. Select a problem in `question_config.py`.
2. Run `00_run_question_lab.py` from this folder.
3. Open `outputs/question_results/interactive_dashboard.html`.

The generated report records the actual mesh, solution files, and an
exact-solution error for the sine-wave verification cases.
